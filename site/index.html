Notes and tasks, kept in your Mac's notch.

Perch is a Mac app for the things you need to do and the things you want to remember. Move the pointer to the notch and today is there. Everything it keeps is a plain Markdown file in a Git repository you own.

Get the source
git clone https://github.com/ben4mn/perch-app.git

Open source. Built from source on an Apple silicon Mac with Xcode 27.

Today, under the pointer

The closed notch shows how much is left today. Hover and it opens: today's tasks, a notepad for the thing you just thought of, and what your agents are doing. Press Option-N from any app to add a task without leaving your work.

Done is one click

Tick a task where you see it. The change is written to the task's file and committed with the rest.

It asks quietly

A reminder, a finished focus session or a question from an agent hangs below the notch with two answers. Nothing takes over your screen.

The last day of your clipboard

Clips keeps what you copied, your screenshots, and files you drop on the notch. Click one to copy it again, or drag it out. It stays in memory only, nothing is kept longer than 24 hours, and items from password managers are skipped.

Tasks are files

Each task is a Markdown file with its dates, its owner and its notes. Perch shows them as Today, Upcoming, a list, a calendar or a board. Because they are files, they sync with Git, they outlive the app, and anything can read them.

Notes that draw what you wrote

Write Markdown and read it properly set: tables, code, formulas, diagrams, sheet music, boards and whiteboards. Edit beside the preview, or just read.

Themes

Perch comes with light and dark themes, and every color can be changed.

Tabs and split view

Open notes and task views in tabs, or two side by side. This is an experiment you can turn on in Settings.

Your agent works in the same notebook

Perch comes with the Perch Relay, a small MCP server. Point Claude Code or another agent at it, and the agent can read your notes, add tasks, and propose that a task is done, with its reasons. You confirm. Every change an agent makes is a Git commit under its own name, so it can be undone.

Plain files in a repository you own

A Perch notebook is a folder. Notes are Markdown. Each area has a Tasks folder of Markdown files. Boards and whiteboards are in open formats. If the folder is a Git repository, Perch commits as you work and pushes to its remote. There is no Perch server and no Perch account.

Open source, and meant to be changed

Perch is one person's app, published so you can make it yours. The repository carries what a coding agent needs: how the code is laid out, how to build and test it, and what was learned the hard way. A demo notebook is included, so there is something to look at on first run.

  1. Clone it: git clone https://github.com/ben4mn/perch-app.git
  2. Open it in Claude Code: cd REPO && claude
  3. Ask: Build Perch and open the demo notebook.

Perch is a personal project. There is no download and it is not notarized: you build it from source. It needs an Apple silicon Mac and Xcode 27. The iPhone app is in the source too.
